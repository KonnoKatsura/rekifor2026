# 会員名簿スプレッドシート 操作ガイド

このガイドは、歴史と伝統文化フォーラムの会員名簿を日常的に操作するための手順書です。

対象スプレッドシート:

- `最新_会員名簿 のコピー`

普段使うタブ:

- `会員入力用`

確認用タブ:

- `会員種別別`
- `会員一覧`
- `会費管理`
- `連絡管理`
- `未納者確認`

## いちばん大事なルール

普段編集するのは、基本的に `会員入力用` だけです。

`会員種別別`、`連絡管理`、`未納者確認` などは自動表示用です。直接入力すると、数式が広がれずに `#REF!` になることがあります。

迷ったら、次のように考えてください。

```text
入力する場所: 会員入力用
見る場所: その他のタブ
```

## 画面の見方

`会員入力用` では、左側の列が固定されています。

右にスクロールしても、左側に次の列が残ります。

- `受付日`
- `会員種別`
- `お名前`
- `フリガナ`

右側へ移動したい時は、下の横スクロールバー、またはトラックパッドの左右スワイプを使います。

## 新しい会員を追加する

1. `会員入力用` タブを開く
2. 表の一番下の空いている行を探す
3. `受付日` に日付を入力する
4. `会員種別` をプルダウンから選ぶ
5. `お名前`、`フリガナ`、連絡先などを入力する
6. 会費やメール対応の状態をプルダウンで選ぶ

日付は次の形で入れると安定します。

```text
2026/08/21
```

## 会員種別を変更する

1. `会員入力用` タブを開く
2. 該当する人の `会員種別` セルをクリック
3. プルダウンから選ぶ

例:

- `正会員`
- `オンライン, 正会員`
- `随時（ビジター）`
- `お試し, 随時（ビジター）`
- `理事`
- `評議員`
- `賛助会員`

入力後、`会員種別別` タブの人数集計にも自動で反映されます。

## 会費入金を記録する

1. `会員入力用` タブを開く
2. `会費入金` 列を探す
3. 該当する人のセルをクリック
4. プルダウンから選ぶ

よく使う選択肢:

- `済`
- `未`
- `不要`
- `確認中`

色の目安:

- `済`: 青
- `未`: 赤
- `不要`: 緑
- `確認中`: 黄

## メール対応を記録する

メール対応に関係する列は、主に次の列です。

- `口座メール済`
- `振込お礼メール`
- `督促`
- `4月 URL送信`
- `6月告知`
- `6月 URL送信`
- `6月レジュメ送信`
- `8月告知`

操作方法は同じです。

1. 該当するセルをクリック
2. プルダウンを開く
3. 状態を選ぶ

選択肢の例:

- `済`
- `未`
- `不要`
- `失敗`
- `確認中`
- `送信予定`
- `再送予定`

## 8月告知を記録する

1. `会員入力用` タブを開く
2. 右へスクロールして `8月告知` 列を探す
3. 該当する人のセルをクリック
4. プルダウンから状態を選ぶ

たとえば、送信済みなら `済` を選びます。

## 未納者を確認する

1. `未納者確認` タブを開く
2. 表示されている人を確認する

このタブは、`会員入力用` の `会費入金` が `未` の人を確認するためのタブです。

直接入力はしません。

## 会員種別ごとの人数を確認する

1. `会員種別別` タブを開く
2. 中段の `会員さん集計` を見る

ここで確認できるもの:

- 種別ごとの人数
- 会員さん合計

上段の `役職・固定枠` は、理事・評議員・賛助会員などを分けて表示しています。

## 連絡状況を確認する

1. `連絡管理` タブを開く
2. 各月の告知やURL送信の状態を見る

このタブは確認用です。

状態を変更したい時は、`会員入力用` タブで変更してください。

## 並べ替えをする

`会員入力用` では、見出し行から並べ替えできます。

1. 並べ替えたい列の見出しにあるメニューを開く
2. 昇順または降順を選ぶ

よく使う並べ替え:

- `フリガナ` 順
- `会員種別` 順
- `会費入金` 順

## 絞り込みをする

特定の条件だけ表示したい時は、見出し行から絞り込みできます。

例:

- `会費入金` が `未` の人だけ見る
- `会員種別` が `正会員` の人だけ見る
- `8月告知` が `未` の人だけ見る

操作:

1. 見出しのメニューを開く
2. 表示したい値だけにチェックを残す
3. OKを押す

元に戻したい時は、フィルタ条件を解除します。

## やってよいこと

- `会員入力用` に新しい会員を追加する
- `会員入力用` のプルダウンを変更する
- `会員入力用` の住所や電話番号などを修正する
- `会員種別別` で人数を見る
- `連絡管理` で送信状況を見る
- `未納者確認` で未納者を見る

## なるべく触らない方がよいこと

- 表示用タブに直接入力する
- 見出し名を手で変更する
- 列を削除する
- 列を途中に挿入する
- 数式が入っているセルを消す
- `設定マスタ` を理由なく変更する

特に見出し名の変更は、別タブの数式やテーブル定義とつながっているため、エラーの原因になりやすいです。

## よくあるトラブル

### `#REF!` が出た

原因:

自動表示の数式が広がる先に、何か文字が残っている可能性があります。

対処:

- 表示用タブに直接入力していないか確認する
- わからなければ、無理に直さず相談する

### 日付が変な表示になった

原因:

Google Sheets が日付として自動変換した可能性があります。

対処:

日付は次の形で入力します。

```text
2026/08/21
```

### 右にスクロールできないように見える

原因:

左側の列が固定されているため、固定線の右側だけが動きます。

対処:

- 下の横スクロールバーを動かす
- トラックパッドで左右にスワイプする

### プルダウンの文字が見えにくい

原因:

プルダウンチップと条件付き書式の相性で、文字色が見えにくくなる場合があります。

対処:

無理に手で色を直さず、相談してください。

## 困った時の判断

迷ったら、この順番で確認します。

1. いま触っているタブは `会員入力用` か
2. 入力したい場所はプルダウン列か
3. 表示用タブに直接入力しようとしていないか
4. 見出し名や列そのものを変えようとしていないか

この4つで迷う場合は、無理に触らず確認するのが安全です。

## 最低限これだけ覚える

```text
入力は 会員入力用
確認は その他のタブ
日付は 2026/08/21 形式
状態は プルダウンから選ぶ
見出し名は 勝手に変えない
エラーが出たら 無理に触らない
```

これで日常運用はだいたい大丈夫です。
