# 歴史と伝統文化フォーラム 会員メール送信ツール 備忘録

作成日: 2026-08-01

用途: 会員向けのお知らせメールを、BCCではなく1人ずつ個別送信し、送信結果をGoogleスプレッドシートに記録する。

## 目的

これまでGmailで1件ずつ手動送信していた会員向けメールを、GoogleスプレッドシートとApps Scriptで半自動化する。

- 受信者同士のメールアドレスが見えないようにする
- BCC一括送信への不安を避ける
- 送信済み、送信日時、送信結果を残す
- 添付チラシPDFを付けて送れるようにする
- 高齢の会員にも読みやすい、シンプルなメール本文にする

Googleスプレッドシート:

ファイル名:

## 構成

| タブ名 | 役割 |
| --- | --- |
| 名簿 | 送信対象者の氏名、敬称、メールアドレス、送信対象チェック、送信結果を管理する |
| メール本文 | 件名、差出人名、返信先、テスト送信先、本文テンプレート、添付ファイルURLを管理する |
| 送信ログ | 送信日時、宛先、件名、結果、エラー内容などを記録する |
| 使い方 | 基本的な運用メモ |

## 名簿タブ

| 列 | 項目 | 必須 |
| --- | --- | --- |
| A | 送信対象 | 必須。送る人だけチェックする |
| B | 氏名 | 必須 |
| C | 敬称 | 任意。通常は「様」 |
| D | メールアドレス | 必須 |
| E | 会員種別 | 任意 |
| F | 状態 | 任意。ただし「停止」の場合は送信しない |
| H | 送信済み | 自動記録。ここがチェック済みだと再送しない |
| I | 送信日時 | 自動記録 |
| J | 送信結果 | 自動記録 |
| K | エラー | 自動記録 |
| L | 最終件名 | 自動記録 |
| M | 最終送信者 | 自動記録 |

最小入力:

```text
送信対象: チェック
氏名: 山田 花子
敬称: 様
メールアドレス: example@example.com
```

会員種別と状態は空欄でも送信できる。

状態が「停止」の場合は、送信対象にチェックが入っていても送らない。

## メール本文タブ

| セル | 項目 | 内容 |
| --- | --- | --- |
| B2 | 件名 | メール件名 |
| B3 | 差出人名 | 受信者に表示される差出人名 |
| B4 | 返信先 | 返信を受けるメールアドレス |
| B5 | テスト送信先 | テストメールを送る宛先 |
| B6 | 本文テンプレート | 実際の本文 |
| B7 | 添付ファイルURL | Google Drive上のPDF/画像URL。空欄なら添付なし |

本文テンプレートで使える差し込み:

```text
{{氏名}}
{{敬称}}
{{会員種別}}
{{個別メモ}}
```

現在は先頭を以下の形にして、氏名と敬称の間にスペースを入れている。

```text
{{氏名}} {{敬称}}
```

## 添付ファイル

添付ファイルを送る場合は、Google DriveにPDFや画像を置き、そのファイルURLを `メール本文` タブの `添付ファイルURL` 欄に貼る。

送信時の動き:

```text
スプレッドシートの添付ファイルURLを読む
↓
Apps ScriptがDrive上のファイルIDを取得する
↓
Driveからファイル本体を取得する
↓
メールに添付して個別送信する
```

受信者がDriveリンクを開く方式ではなく、メールにファイル本体が添付される。

複数添付したい場合は、URLを改行で並べる。

推奨:

- チラシはPDF推奨
- 1通あたり合計25MB未満にする
- 本送信前に必ずテスト送信する

## Apps Scriptのメニュー

| メニュー | 役割 |
| --- | --- |
| テスト送信 | `メール本文` タブのテスト送信先だけに送る |
| チェック行へ送信 | `名簿` タブで送信対象にチェックした人へ個別送信する |
| 選択行の送信済みをリセット | 選択行の送信済み情報を消す |

送信条件:

- `送信対象` がチェック済み
- `送信済み` が未チェック
- メールアドレスが入っている
- 状態が `停止` ではない

送信後:

- `送信済み` にチェックが入る
- `送信日時` が入る
- `送信結果` が入る
- `送信ログ` に記録される

## テスト送信と本送信の違い

```text
テスト送信:
メール本文タブのB5「テスト送信先」にだけ送る。
名簿のチェックは見ない。

チェック行へ送信:
名簿タブのA列「送信対象」にチェックした人へ送る。
送信済みの人には送らない。
```

## 一括チェック

名簿タブのA列チェックボックスは一括操作できる。

```text
A2:A21 のようにチェックしたい範囲を選択
↓
スペースキー
```

もう一度スペースキーを押すと、まとめてチェックを外せる。

注意:

`送信済み` 列を一括チェックすると、スクリプトが「送信済み」と判断して送らなくなる。

## 送信元アドレスについて

現在のApps Scriptは、スクリプトを承認したGoogleアカウントから送信する。

`MailApp` では、送信元アドレスそのものを自由に指定することはできない。

できること:

- 差出人名を `一般社団法人 歴史と伝統文化フォーラム 事務局` のように表示する
- 返信先を `rekifor2026@gmail.com` にする

送信元アドレスそのものを `rekifor2026@gmail.com` にしたい場合は、`rekifor2026@gmail.com` のGoogleアカウントでスプレッドシートとApps Scriptを開き、そのアカウントで承認して送信するのが一番確実。

## スマホ表示について

iPhoneのGmailアプリなどでは、本文が画面幅や文字サイズ設定に応じて自動で折り返される。

これは受信者側の環境によるもので、完全に固定することは難しい。

対策:

- 長い行は避ける
- 意味の区切りであらかじめ改行する
- 全角スペースを使った位置調整は避ける
- 高齢者向けには短めの行で読みやすさを優先する

## 通常の運用手順

```text
1. 名簿タブに宛先を入力する
2. メール本文タブで件名、本文、添付ファイルURLを確認する
3. テスト送信先に自分のメールアドレスを入れる
4. メール送信 → テスト送信
5. スマホでも表示と添付を確認する
6. 名簿タブで送信したい人の送信対象にチェックする
7. メール送信 → チェック行へ送信
8. 送信ログを確認する
```

## 注意点

- 本送信前に必ずテスト送信する
- 添付ファイルURLが間違っているとエラーになる
- Driveファイルを添付するには、送信するGoogleアカウントがそのDriveファイルを読める必要がある
- 個人GmailではApps Scriptの送信数に上限がある
- 20人程度なら現実的に運用しやすい
- 送信済み列を手でチェックすると、その人には送られなくなる

## この仕組みの要点

このツールは、メール配信サービスではなく、Googleスプレッドシートを管理画面にした簡易メール送信ツール。

BCCではなく、Apps Scriptが1人ずつ個別メールとして送る。

そのため、受信者同士のメールアドレスは見えない。

送信後はスプレッドシートに結果が残るため、手動Gmail送信よりも確認しやすく、二重送信も防ぎやすい。
