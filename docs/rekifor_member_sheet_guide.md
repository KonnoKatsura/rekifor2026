# 歴史と伝統文化フォーラム 会員名簿スプレッドシート整理ガイド

このメモは、2026年8月1日に会員名簿スプレッドシートを整理した内容を、Tがあとから見返せるようにまとめたものです。

対象ファイル:

- Google Sheets: `最新_会員名簿 のコピー`
- 主に触るタブ: `会員入力用`
- 目的: 会員名簿を、並べ替え・集計・メール送信管理に使いやすい形へ整える

## まず結論

今後の基本ルールはこれです。

- 普段編集するのは `会員入力用` タブ
- `会員種別別`、`会員一覧`、`会費管理`、`連絡管理`、`未納者確認` は表示・確認用
- 表示用タブは数式で自動表示しているため、基本的に直接編集しない
- プルダウン列は、文字を手入力するより選択肢から選ぶ
- 見出し名を変えたい時は、テーブル定義や表示用タブの数式も絡むので慎重に行う

## 元の課題

元の `会員名簿` は、見た目上は名簿として使えていましたが、表データとしては少し扱いにくい状態でした。

- 途中に区切り行や役職名だけの行が混ざっていた
- 名前順、会員種別順に並べ替えにくかった
- Q列以降に連絡履歴が継ぎ足しのように存在していた
- 日付が Google Sheets の内部日付番号や英語式表示になりやすかった
- プルダウンや色付き表示を整えたいが、既存の表構造が複雑だった

そこで、原本を直接大きく壊さず、別タブを作って整理しました。

## 作ったタブの役割

### `会員入力用`

今後のメイン入力タブです。

ここだけ触ればよい、という運用を想定しています。

主な特徴:

- A列からU列までを入力用テーブル化
- 1行目が見出し
- AからD列を固定
- 右にスクロールしても、受付日・会員種別・お名前・フリガナが残る
- 会費や連絡履歴はプルダウン化
- `済`、`未`、`不要` などを色で見分けられる

触ってよい列の例:

- `受付日`
- `会員種別`
- `お名前`
- `フリガナ`
- `メールアドレス`
- `住所`
- `電話番号`
- `会費入金`
- `口座メール済`
- `振込お礼メール`
- `督促`
- `8月告知`

### `会員名簿_整理版`

元の名簿を、名前がある行だけ抽出して整理した表示用タブです。

基本的には直接編集しません。

### `会員一覧`

会員種別、名前、フリガナだけを見るための簡易一覧です。

メールアドレスや住所などを見せずに確認したい時向けです。

### `会員種別別`

会員種別ごとに一覧と人数を確認するためのタブです。

2026年8月1日時点では、次のように分けています。

- 上段: `役職・固定枠`
- 中段: `会員さん集計`
- 下段: `会員さん一覧（種別別）`

上段の役職・固定枠:

- `理事`
- `評議員`
- `（評議員）`
- `賛助会員`

中段の会員さん集計:

- 役職系を除いた会員種別ごとの人数
- 役職系を除いた会員さん合計

下段の会員さん一覧:

- 役職系を除いた会員さんだけを表示
- 会員種別順、フリガナ順で並ぶ

### `会費管理`

会費・メール・督促まわりを確認するための表示用タブです。

### `連絡管理`

メール送信や告知履歴を見るための表示用タブです。

現在の見出しは、主に次のような形です。

- `4月 URL送信`
- `6月告知`
- `6月 URL送信`
- `6月レジュメ送信`
- `8月告知`

元は `6月告知(2)` という重複回避用の名前でしたが、用途に合わせて `8月告知` に変更しました。

### `未納者確認`

会費入金が `未` の人を確認するための表示用タブです。

### `設定マスタ`

プルダウン候補の元データ置き場です。

ここには、会員種別やステータスの候補を置いています。

例:

- `正会員`
- `オンライン, 正会員`
- `随時（ビジター）`
- `済`
- `未`
- `不要`
- `確認中`
- `送信予定`
- `再送予定`

## テーブル化とは何か

Google Sheets のテーブル化は、普通の表に少しデータベースっぽい性質を持たせる機能です。

今回の `会員入力用` では、A列からU列までを `会員入力テーブル` として扱っています。

テーブル化すると、主に次のことができます。

- 見出しから並べ替えしやすい
- 見出しから絞り込みしやすい
- 列ごとに種類を決められる
- プルダウン列を作れる

ただし注意点もあります。

- テーブル列名を手で変えると、関連する数式やテーブル定義とズレることがある
- 日付列は Google Sheets が勝手に表示形式を変えることがある
- プルダウンのチップ色は外部操作から細かく指定しにくい

## 日付を文字列にした理由

最初は `受付日` と `参加日` を日付列として扱おうとしました。

しかし Google Sheets のテーブル機能が、日付表示を `4/2/2026` のような形式に戻してしまいました。

そこで、見た目の安定を優先して、日付は次のような文字列として固定しました。

```text
2026/08/21
```

この形なら、Tが見てもわかりやすく、並べ替えにも比較的強いです。

## プルダウンと色分け

`会員入力用` では、会費や連絡履歴の列をプルダウンにしています。

代表的な選択肢:

- `済`
- `未`
- `不要`
- `失敗`
- `確認中`
- `送信予定`
- `再送予定`

色分けは、Google Sheets のプルダウンチップそのものではなく、条件付き書式も使って見やすくしています。

ざっくりした意味:

- `済`: 青
- `未`: 赤
- `不要`: 緑
- `失敗`: 赤
- `確認中`: 黄
- `送信予定` / `再送予定`: 紫

一度、白文字で見えにくくなったため、文字色は黒寄りに戻しました。

## 固定とは何か

固定とは、スクロールしても特定の行や列を画面に残す機能です。

`会員入力用` では、上の見出し行と左側の列を固定しています。

目的:

- 右へスクロールしても、どの会員の行を見ているか迷わないようにする
- 連絡履歴や会費欄を見ている時も、名前を見失わないようにする

固定線の右側だけが横スクロールします。

## 自分で編集するときの基本操作

### 新しい会員を追加する

1. `会員入力用` を開く
2. 一番下の空いている行に入力する
3. `会員種別` はプルダウンから選ぶ
4. 日付は `2026/08/21` の形で入れる

### 会費入金を変更する

1. `会員入力用` の `会費入金` 列を見る
2. 該当セルをクリック
3. プルダウンから `済`、`未`、`不要` などを選ぶ

### 8月告知を記録する

1. `会員入力用` の右側へスクロールする
2. `8月告知` 列を見る
3. 該当セルをクリック
4. `済`、`未`、`不要`、`送信予定` などを選ぶ

### 会員種別ごとの人数を見る

1. `会員種別別` タブを開く
2. 中段の `会員さん集計` を見る
3. 種別ごとの人数と合計を確認する

## 自分で触ると危ないところ

### 見出し名の変更

見出し名は、表示用タブやテーブル定義とつながっています。

たとえば `6月告知(2)` を `8月告知` に変える時は、次の両方をそろえる必要がありました。

- `会員入力用` のU列見出し
- `会員入力テーブル` の列名
- `連絡管理` の表示式

見出しだけ手で変えると、別タブが `#REF!` になることがあります。

### 表示用タブへの直接入力

`会員種別別` や `連絡管理` は、1つのセルから表全体を自動表示しています。

このような数式は、右や下へ自動で広がります。

その広がる先に何か手入力があると、次のようなエラーになります。

```text
#REF!
```

意味:

```text
数式の結果を広げたいけれど、広げる先に既存の文字があるので表示できません
```

対処:

- 表示用タブには直接入力しない
- もし `#REF!` が出たら、広がる先に残っている文字を消す
- わからなければ、こーちゃんに任せる

## 今日使った主な数式の考え方

ここはT向けの「アレルギーを起こしにくい説明」です。

### `FILTER`

条件に合う行だけ抜き出す関数です。

今回の感覚:

```text
名前が入っている人だけ取り出す
```

または、

```text
理事・評議員・賛助会員を除いた人だけ取り出す
```

### `SORT`

並べ替える関数です。

今回の感覚:

```text
会員種別順、フリガナ順に並べる
```

### `UNIQUE`

重複を除いて、種類だけを取り出す関数です。

今回の感覚:

```text
正会員、オンライン正会員、随時参加者など、種別名だけ一覧にする
```

### `COUNTIF`

条件に合う数を数える関数です。

今回の感覚:

```text
正会員が何人いるか数える
```

### `COUNTA`

空白ではないセルを数える関数です。

今回の感覚:

```text
名前が入っている人の人数を数える
```

### `REGEXMATCH`

文字の中に、指定した言葉が含まれているか調べる関数です。

今回の感覚:

```text
会員種別に「理事」「評議員」「賛助会員」が含まれているか調べる
```

## 役職系を除外する考え方

`会員種別別` では、上段に役職系を分けました。

役職系:

```text
理事
評議員
（評議員）
賛助会員
```

下段の会員さん集計では、これらを除外しています。

理由:

- 人数があまり変わらない固定枠として扱いたい
- 通常の会員数集計と混ざるとわかりにくい
- 代表や事務局が見る時に、会員さん人数だけ確認しやすい

## 今日の変更履歴

1. `会員入力用` をメイン入力タブとして整備
2. 日付列を `yyyy/mm/dd` 形式の文字列に固定
3. 会費・連絡履歴系の列をプルダウン化
4. プルダウンの状態を色で見分けられるようにした
5. 文字色が白で見えにくかったため、黒寄りに修正
6. AからD列を固定し、右スクロール時も名前を見失いにくくした
7. `会員種別別` を役職系と会員さんで分離
8. 会員さん種別ごとの人数と合計が出るようにした
9. `6月告知(2)` を `8月告知` に変更
10. `連絡管理` も `会員入力用` から表示する形へ更新

## 今後のおすすめ運用

普段はこの流れで十分です。

1. `会員入力用` に入力する
2. 会費や告知状況はプルダウンで選ぶ
3. 人数を見たい時は `会員種別別`
4. 連絡状況を見たい時は `連絡管理`
5. 未納確認は `未納者確認`

見出し名、列追加、タブ構造変更、数式修正は、表全体に影響しやすいので、必要になったらこーちゃんに頼むのが安全です。

## 困った時の見分け方

### `#REF!` が出た

表示用タブの自動展開先に、何か文字が残っている可能性があります。

### 日付が変な表示になった

Google Sheets が日付として解釈し直した可能性があります。

安定させるなら `2026/08/21` の形で入れます。

### プルダウンの色や枠が思った通りにならない

Google Sheets のプルダウンチップ色は、外部操作から細かく制御しにくいです。

今回は条件付き書式も使って、セル全体の色で見分ける方針にしています。

### 右にスクロールしたら途中で止まったように見える

固定列の境界線の右側だけが動いています。

下の横スクロールバーか、トラックパッドの左右スワイプで右へ移動できます。

## こーちゃんへの依頼メモ

次に大きく直す時は、次の方針が安全です。

- 原本 `会員名簿` はなるべく壊さない
- 入力は `会員入力用` に寄せる
- 表示用タブは `会員入力用` 参照へ寄せる
- 個人情報を外へ出さない
- 直接編集する前に、対象範囲と数式の展開先を確認する
- 見出し変更時は、テーブル列名と表示用数式も合わせて直す

このガイドは、Tがスプレッドシートの構造を思い出すための説明書です。
実務で迷った時は、まず `会員入力用` だけ触る、を基本にしてください。
